# orange-internship
Project realized during an internship at Orange Egypt during the summer of 2025. Small backend Spring Boot application.
## Orange Egypt — Backend REST API

REST API backend built during an internship at Orange Egypt, summer 2025.

### What it does
Manages user accounts, gift card redemption and eligibility verification.

### Built with
Java, Spring Boot, JDBC, JPA, PostgreSQL

### How to run
Clone the repo, configure your PostgreSQL database and run with IntelliJ.
